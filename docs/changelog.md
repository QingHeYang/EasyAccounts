## 版本历史

### 2.7.0 (2026-05)

**重要特性**
- 新增 **定时记账**：周期性账单（订阅、房贷、水电、工资等）按规则自动生成流水，支持每日 / 每周 / 每月 / 每年，可暂停 / 修改 / 查看执行历史
- 新增 **自动月度 Excel**：每月按时自动生成账单 Excel，可邮件发送，无需手动导出
- 新增 **站内通知中心**：双端顶栏铃铛 + 未读徽章，定时记账提醒、Excel 生成等通知统一收口
- 新增 **统计页日支出折线图**：选月查看当月每天支出趋势
- 新增 **明细页日合计**：每天总支出直接显示在日期旁
- **设置全面 UI 化**：邮件 SMTP、备份时间、登录方式、自动 Excel 全部在前端「系统设置」配置，改完立即生效，**无需重启容器**
- AI 操作失败时前端会显示"为什么失败"，不再静默卡住

**新增功能**
- 流水图片附件上限 3 → 9 张
- 移动端记账「金额 + 收支」合并到一张大卡片，直接 chip 选支出 / 收入 / 转账
- 移动端 4 个分类选择入口（记账 / 模板 / 定时记账 / 统计）统一为网格视图
- 移动端统计页筛选改成顶部折叠面板，时间快捷选项 + 自定义起止日期集中展示
- 移动端流水加载有「加载中」提示，网络错误时会显示「加载失败」
- PC 端总览右侧 4 张卡片（统计 / 趋势 / 日历 / 筛选）可拖动调整顺序
- PC 端流水页加每日趋势迷你图，可点开看大图柱状对比
- 浏览器自动填充密码：登录页对接 Chrome / Edge / Safari 钥匙串
- 升级到新版本时有礼花庆祝动画 🎉
- 双端图标全部统一图标库，视觉更整齐
- 邮件升级为带品牌标头的 HTML 格式

**Bug 修复**
- 修复偶尔导出 Excel 卡住 / 超时的问题
- 修复 AI 使用部分模型时的连锁稳定问题（聊天中断、上下文混乱等）
- 修复 SQL 备份失败时仍发出空附件邮件
- 修复删除流水后图片文件没被清理
- 修复邮件配置输入框在暗黑模式下显示错位
- 修复手机端连续添加分类后需要点多次返回（issue #27）
- 修复创建定时记账规则后立即提醒里账户 / 分类显示成「—」
- 修复某些操作失败的错误提示一闪而过看不见
- 安全修复：图片下载接口防止恶意路径访问

**技术特性**
- 内置邮件发送，**废弃独立的 WebHook 容器**，部署少一个镜像
- 镜像瘦身：整套部署包从 ~2GB 砍到 ~1.24GB，首次拉取更快
- MySQL 连接池 + 缓冲区调优，运行期稳定性提升
- AI 错误统一结构化返回，前后端协议更规范
- AI 提示词与工具描述与后端业务全面对齐，工具调用准确率提升

**升级提示**
- ⚠️ 老用户升级请删除 `docker-compose.yml` 中整段 `webhook:` 服务块
- ⚠️ `server:` 下 `SQL_BACKUP_TIME` / `ENABLE_LOGIN` / `EXPIRED_TIME` / `SINGLE_LOGIN` 已废弃，删除即可，启动后在前端「系统设置」重新配置
- ⚠️ 邮件配置（原 webhook 容器各 `SMTP_*`）需在前端「系统设置 → 邮件」重新填写
- 反向代理用户请确保 nginx 配置含 WebSocket Upgrade 三件套，详见 issue [#23](https://github.com/QingHeYang/EasyAccounts/issues/23)

### 2.6.0 (2026-01)

更新视频：[【开源记账软件 EasyAccounts v2.6.0 全新界面！】](https://www.bilibili.com/video/BV1BErCBsEMQ)

**重要特性**

- 支持日间/夜间模式切换
- AI 增加 MCP 功能（SSE / Streamable-HTTP），可使用第三方 AI 工具

- 账户增加资产与负债属性，现有账户全部转为资产账户，负债账户需要新增

**新增功能**
- 不计入总金额功能完善，内部转账不计入总金额选项拆分成转出不计入与转入不计入
- 认证模式优化：固定时间退出 → 滑动时间退出，支持多端登录
- AI 工具显示优化，不再显示参数，新增可点击交互工具
- AI 记账/更新会在备注中默认增加 `#AI记账` `#AI更新` 标签，方便溯源
- 总览月度概览标注收入、支出、结余、负收入
- 桌面端总览增加年度收支趋势
- 双端总览增加隐私按钮
- 快记模板备注会默认增加模板名称
- 统计页面图表重构，可快速排除某分类
- 统计-分类统计增加最高最低标注、折线面积图
- 设置页面增加 AI+ 设置（MCP 地址、Token 统计、对话工具数目）
- 设置页面增加系统信息（深浅肤色、认证信息、备份信息、各组件版本号）
- Excel 模板优化：xls → xlsx，收入绿色、支出红色

**Bug 修复**
- 修复不计入总金额记账出现 500 问题
- 修复 AI 选择一级分类记账导致统计分类找不到明细的问题
- 修复移动端桌面端账户页面不统一问题

**技术特性**
- 前端 JS → TS，vue-cli → Vite，引入 ECharts、Element Plus、Vant
- 后端 Spring 2.x → 3.x，Java 11 → 17
- Agent 框架（koalaq_hub）优化，引入 FastMCP
- 部署简化：无需复制初始化数据库文件（已内置到 MySQL 镜像）
