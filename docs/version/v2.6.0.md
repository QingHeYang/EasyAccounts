# v2.6.0

更新日期：2025-01-xx

## 重要特性

- 新增 PC 端，重构移动端，界面完全重新设计，更符合现代审美
- 支持日间/夜间模式切换
- AI 增加 MCP 功能（SSE / Streamable-HTTP），可使用第三方 AI 工具
- AI 增加图像识别功能（需 VL 大模型支持，普通模型上传图片会导致当前对话作废）
- 账户增加资产与负债属性，现有账户全部转为资产账户，负债账户需要新增

## 新增功能

1. 不计入总金额功能完善，内部转账不计入总金额选项拆分成转出不计入与转入不计入（**不计入总金额的确立是为了记录借钱还钱等操作**，信用卡等初始负债请新建负债账户）
2. 认证模式优化：固定时间退出 → 滑动时间退出，支持多端登录（可在 compose 中配置）
3. AI 工具显示优化，不再显示参数，新增可点击交互工具
4. AI 记账/更新会在备注中默认增加 `#AI记账` `#AI更新` 标签，方便溯源
5. 总览月度概览标注收入、支出、结余、负收入
6. 桌面端总览增加年度收支趋势
7. 双端总览增加隐私按钮
8. 快记模板备注会默认增加模板名称
9. 统计页面图表重构，可快速排除某分类，无需去设置里操作
10. 统计-分类统计增加最高最低标注、折线面积图
11. 设置页面增加 AI+ 设置（MCP 地址、Token 统计、对话工具数目）
12. 设置页面增加系统信息（深浅肤色、认证信息、备份信息、各组件版本号）
13. Excel 模板优化：xls → xlsx，收入绿色、支出红色，更直观

## Bug 修复

1. 修复不计入总金额记账出现 500 问题，原因是对应账户未初始化不计入总金额字段
2. 修复 AI 选择一级分类记账导致统计分类找不到明细的问题
3. 修复移动端桌面端账户页面不统一问题

## 技术特性

- 前端 JS → TS，vue-cli → Vite，引入 ECharts、Element Plus、Vant
- 后端 Spring 2.x → 3.x，Java 11 → 17
- Excel 相关库升级
- Agent 框架（koalaq_hub）优化，引入 FastMCP，内部工具框架升级
- 部署简化：无需复制初始化数据库文件（已内置到 MySQL 镜像）

## Compose 变更

### server 容器

新增环境变量：
```yaml
- SINGLE_LOGIN=true    # 是否启用单点登录，默认 false
```

### ai 容器

新增环境变量：
```yaml
- MCP_SERVER_ENABLED=false      # 是否启用 MCP 服务器
- MCP_TRANSPORT_MODE=sse        # MCP 传输模式: sse 或 streamable-http
```

## 升级说明

1. 备份数据库（重要！）
2. 拉取最新代码
3. 更新镜像并重启

```bash
git pull
./update-docker.sh
docker compose down
docker compose up -d
```
