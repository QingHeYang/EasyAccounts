# v2.7.0

更新日期：2026-05

## 重要特性

- 新增 **定时记账**：周期性账单（订阅、房贷、水电、工资等）按规则自动生成流水，支持每日 / 每周 / 每月 / 每年，可暂停 / 修改 / 查看执行历史
- 新增 **自动月度 Excel**：每月按时自动生成账单 Excel，可邮件发送，无需手动导出
- 新增 **站内通知中心**：双端顶栏铃铛 + 未读徽章，定时记账提醒、Excel 生成等通知统一收口
- 新增 **统计页日支出折线图**：选月查看当月每天支出趋势
- 新增 **明细页日合计**：每天总支出直接显示在日期旁
- **设置全面 UI 化**：邮件 SMTP、备份时间、登录方式、自动 Excel 全部在前端「系统设置」配置，改完立即生效，**无需重启容器**
- AI 操作失败时前端会显示"为什么失败"，不再静默卡住

## 升级说明

1. **备份数据库**（重要！）
2. 编辑 `docker-compose.yml`：
   - 删除整段 `webhook:` 服务块
   - 删除 `server:` 下的 `SQL_BACKUP_TIME` / `ENABLE_LOGIN` / `EXPIRED_TIME` / `SINGLE_LOGIN` 4 个废弃环境变量
   - 镜像版本号改成 v2.7.0
3. 拉取最新镜像并重启：

```bash
git pull
./update-docker.sh
docker compose down
docker compose up -d
```

4. 打开前端「**系统设置**」页，把原来 docker-compose 里的邮件 / 备份 / 鉴权配置**手动重新填一遍**

> **反向代理用户**：如果你在外面套了 nginx 反代，确保 nginx 配置里有 WebSocket Upgrade 三件套（`proxy_http_version 1.1` + `proxy_set_header Upgrade $http_upgrade` + `proxy_set_header Connection "upgrade"`），否则 AI 助手连不上。详见 issue [#23](https://github.com/QingHeYang/EasyAccounts/issues/23) 评论。
